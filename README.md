# Robins Chiropractic Center

A static single-page website. The source to edit and publish is `dist/index.html`, `dist/styles.css`, `dist/app.js`, and `dist/assets/`. The original unused framework starter remains preserved outside `dist`; no package installation is needed for this static site.

Run a local static server with its root set to `dist`. Sites identity and the static publish directory are configured in `.openai/hosting.json`. Keep the same Sites project ID.

See BRIEF.md for design decisions and VERIFICATION.md for content and launch needs.
